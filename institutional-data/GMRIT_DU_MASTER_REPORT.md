### Campus Room Numbering Convention
Format: **`[Block Number]-[Floor Code]-[Room Number]`** (Short code omits hyphens, e.g., `5-S-10` = `5S10`)
- **Block:** `1` to `6` (Blocks I–VI)
- **Floor:** `G` = Ground Floor, `F` = First Floor, `S` = Second Floor
- **Serial:** 2-digit room number (`01`–`16`)
